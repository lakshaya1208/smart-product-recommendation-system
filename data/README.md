# Dataset

`interactions.csv` is a reproducible synthetic dataset generated by `scripts/generate_dataset.py` with seed `42`.

Columns:

- `customer_id`: demo customer identifier.
- `product_id`: demo product identifier.
- `product_category`: product category.
- `product_price`: product price in INR.
- `views`: number of times the customer viewed the product.
- `cart_additions`: number of times the customer added the product to cart.
- `purchases`: number of purchases in the current interaction window. This is used to create the classification target and is **not** used as a model feature.
- `previous_purchases`: customer's purchase count before the current interaction window.
